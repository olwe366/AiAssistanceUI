## 📋 Overview

**Cybersecurity Guardian** is an intelligent, GUI-based cybersecurity awareness chatbot designed to educate users about online safety through interactive conversations, voice recognition, and personalized responses. Built with WPF and C#, this application provides a modern, user-friendly interface for learning about critical cybersecurity topics.

### 🎯 Purpose
In an era where cyber threats are increasingly sophisticated, this chatbot serves as an accessible educational tool to help users understand and implement cybersecurity best practices in their daily digital lives.

## ✨ Features

### 🎨 Graphical User Interface
- **Modern Dark Theme** - Eye-friendly design with professional color scheme
- **Chat Bubble Interface** - Natural conversation flow with distinct user/bot bubbles
- **ASCII Art Integration** - Custom cybersecurity-themed ASCII logo in header
- **Responsive Design** - Adapts to different window sizes
- **Smooth Animations** - Visual feedback for interactions

### 🎤 Voice Capabilities
- **Text-to-Speech (TTS)** - Bot speaks responses aloud
- **Speech Recognition** - Hands-free voice input
- **Voice Greeting** - Welcome message spoken on startup
- **Status Indicators** - Visual feedback for voice recognition state

### 🧠 Core Intelligence

#### Keyword Recognition
Detects cybersecurity topics and provides relevant, informative responses:
- 🔐 **Password Safety** - Strong passwords, 2FA, password managers
- ⚠️ **Scam Detection** - Recognizing and avoiding online scams
- 🔒 **Privacy Protection** - Data privacy best practices
- 🎣 **Phishing Prevention** - Spotting fake emails and messages
- 🦠 **Malware Protection** - Defending against viruses and malware
- 🔐 **Encryption** - Understanding data encryption
- 💾 **Data Backup** - 3-2-1 backup strategy

#### Random Responses
Uses arrays and lists to provide varied, engaging responses:
- Multiple response variations for each topic
- Random selection keeps conversations fresh
- Prevents repetitive interactions

#### Conversation Flow
Maintains natural dialogue with context awareness:
- Handles follow-up questions ("tell me more", "another tip")
- Remembers current topic for continuation
- Seamless topic transitions
- Context-aware responses

#### Memory & Recall
Personalizes interactions by remembering user information:
- **Name Storage** - "My name is John" → Bot remembers
- **Interest Tracking** - "I'm interested in privacy" → Bot recalls topic
- **Personalized Responses** - Uses stored info in conversations
- **Memory Status Display** - Shows what bot remembers

#### Sentiment Detection
Emotionally intelligent responses based on user mood:
- **😟 Worried** - Provides reassurance and practical steps
- **😤 Frustrated** - Simplifies explanations with encouragement
- **🤔 Curious** - Offers detailed information and resources
- **😊 Neutral** - Standard informative responses

#### Error Handling
Robust error management for professional-grade reliability:
- Graceful handling of unrecognized inputs
- Helpful default responses
- No crashes or unexpected terminations
- Voice recognition fallback for unavailable hardware
